# kaup reference instantiation

This directory is a **reference example** of how one project (kaup) filled
the `constitution-template.md` slots. It is NOT part of the generic
kaup-bridge extension — new projects should start from
`../../constitution-template.md` and use this only as a guide.

## What's here

- `constitution.md` — kaup's instantiated 9-article constitution: a 4-repo
  workspace (kaup-design docs SSOT / kaup-core / kaup-frontend / kaup-artifacts),
  `kaup-cli` as the primary CLI, date-slug feature-ids.

This shows the shape of a filled constitution for a real multi-repo,
CLI-first project.
